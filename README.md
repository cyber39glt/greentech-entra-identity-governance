# Microsoft Entra ID Identity Governance for a Growing Organization

*Work in progress — this README will be completed at the end of the project.*

A hands-on identity governance lab for **GreenTech Solutions Ltd.**, a fictional 250-person renewable energy company. The project designs and tests joiner, mover, leaver and contractor lifecycles in Microsoft Entra ID using free-tier features, and clearly separates what was implemented from what was only designed because it needs paid licensing.

## Repository structure

| Folder | Contents |
|---|---|
| `01-company` | Company profile, org structure, risks, requirements, access policies |
| `02-staff-register` | Fictional staff and role register (CSV) |
| `03-requirements-risk` | Business requirements and risk assessment |
| `04-architecture` | Architecture diagrams |
| `05-identity-design` | Naming standards, user and group design, RBAC model |
| `06-procedures` | Joiner, mover, leaver and contractor procedures |
| `07-configuration` | Security configuration notes |
| `08-testing` | Test plans and results |
| `09-evidence` | Redacted screenshots |
| `10-monitoring-audit` | Audit and sign-in log evidence |
| `11-licensing` | Licensing limitations and recommendations |
| `12-final-report` | Final assessment report |
| `scripts` | Helper scripts (no secrets) |

## Disclaimer

All people, companies, domains and applications are fictional. No passwords, tokens, tenant IDs or personal data are published in this repository.
